## 決まったこと

- **地：ダーク**（近黒 `#120F0A`〜`#17150F`）。ベージュ系は「自然派/カフェに見える」ため不採用。
- **アクセント：朱赤 → 山吹の“グラデ”**（ベタ塗りでなく）。「2本の糸が縒り合い、人の働き＝朱赤 → 成果＝山吹 になる」を色で表す。
  - コア・グラデ（暗地用）：`linear-gradient(100deg,#E4572E 0%,#E4A02B 100%)`
  - 3点版：`linear-gradient(100deg,#C8452A,#E4572E 42%,#E4A02B 100%)`（暗地では朱赤#C8452Aが沈むので#E4572Eを起点に）
- **グラデの居場所（限定）：** 背景グロー／縒り線・区切り／プライマリCTAの縁／キーワードの下線／番号・ドット。
  - **グラデ文字は使わない**（keyword は“下線”で意味だけ残す）。過剰グラデ＝§19のNG回避。
- **グラスモーフィズム：** エアリー（低ティント `rgba(24,20,16,0.30)` ＋強ブラー22px）。向こうの朱×山吹グローがリッチに透ける。
  - **エッジ上質化：** 細ボーダー1本でなく「上からの光ハイライト `inset 0 1px 0 rgba(255,255,255,.16)` ＋柔らかい大影 `0 24px 50px rgba(0,0,0,.42)`」。
- **プライマリボタン：** 黒地 `#0E0C0A` ×グラデ縁（mask合成）＋オレンジの外グロー ＝ “光る黒い鍵”。
- **グロー：** `mix-blend-mode:screen` で朱赤・山吹・明橙を重ね、交差部が溶けた金橙（molten）に。可読性はradialスクリム＋見出しtext-shadowで担保。

## フォント（確定・2026-07-29）
- 全面ゴシック方針。Google Fonts 和文6種を比較 → [`font-candidates.html`](font-candidates.html)（ダーク地・1画面）。
- **見出し：Zen Kaku Gothic New（温かい知性）／本文：IBM Plex Sans JP（知的・実務・英数字が上質）**。Noto Sans JP はフォールバックに使用。
- **見出しの字間：人格（余白・急かさない）に合わせて開けめ**に確定方向。現状値 = Zen +0.06 / Plex +0.05 / Murecho +0.07 / M PLUS 2 +0.06 / Noto +0.06 / BIZ +0.08 em。→ design-system化する時は「見出し letter-spacing ≈ +0.06em」を基準に。
- 見出し＋本文の2書体構成に確定。
